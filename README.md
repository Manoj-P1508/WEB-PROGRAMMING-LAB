# Web Programming Lab (24BCA51P)

MEWA Vanguard Business School — Department of Computer Applications
Solutions for the Web Programming Lab course.

**Teaching Hours:** 03 Hours/Week | **Exam Duration:** 3 Hours | **Credits:** 02 | **Max Marks:** 50 (Exam 40 + IA 10)

## Structure

```
├── programs/     → all HTML program files (index + p1–p16)
├── css/          → external stylesheet(s) used by the programs
└── images/       → images used by the programs (logo, lab photo, campus photo, etc.)
```

Open `programs/index.html` in a browser to navigate between programs.

## Notes

- `programs/p4.html`, `programs/p8.html`, and `programs/p9.html` reference images/CSS via
  `../images/...` and `../css/style.css` — that's why the HTML files live inside the
  `programs/` folder, one level below `images/` and `css/`.
- `images/collegeLogo.png`, `images/lab.jpeg`, and `images/college.jpeg` are included, so
  `p4.html` and `p8.html` display correctly.

## How to run

Each file is self-contained HTML/CSS. No build steps or dependencies are required — just open
`programs/index.html` (or any individual program file) in a web browser.
